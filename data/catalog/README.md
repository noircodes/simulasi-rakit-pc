# Catalog data

Data from [BuildCores OpenDB](https://github.com/buildcores/buildcores-open-db), licensed under
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Source release: the OpenDB
commit in `meta.json`.

Changes: only the CPU, Motherboard, RAM, GPU, Storage, PSU, PCCase and CPUCooler folders are used;
each record is reduced to the fields this app needs (see `normalizePart` in `lib/catalog.ts`),
sockets and form factors are normalized to one spelling, laptop (SO-DIMM) memory is dropped, and
GPU power is estimated from the chipset when OpenDB has none.

These files are an adaptation of OpenDB and are shared under the same CC BY-NC-SA 4.0 license.
They are regenerated by `npm run sync:catalog` (daily via `.github/workflows/sync-catalog.yml`);
do not edit them by hand.
